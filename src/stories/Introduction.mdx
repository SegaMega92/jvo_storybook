# Дизайн-система JVO

Добро пожаловать в документацию дизайн-системы JVO — лендинга для AI-агента управления продажами на маркетплейсах.

## Структура компонентов

### Foundations (Основы)
Базовые элементы дизайн-системы:
- **Typography** — типографика, шрифты RF Dewi Extended и Manrope
- **Colors** — цветовая палитра (фиолетовый `#C16FFB`, тёмный `#300247`, светлый `#EAD7FE`)
- **Patterns** — паттерны (точечный паттерн для фонов)

### Components (Компоненты)
Переиспользуемые UI-элементы:
- **Button** — кнопки (primary, secondary, outline, ghost)
- **IconButton** — кнопки с иконками
- **Typography** — компонент типографики
- **SectionHeader** — заголовок секции с тегом, заголовком и кнопкой
- **FeatureCard** — карточка фичи с изображением
- **Aurora** — анимированный градиентный фон
- **LogoMarquee** — бегущая строка с логотипами

### Sections (Секции)
Крупные блоки страницы:
- **Header** — навигация сайта
- **HeroSection** — главный экран с заголовком и CTA
- **HeroBlock** — блок с заголовком секции
- **FeatureSlider** — слайдер с фичами (автоответы)
- **FeatureSliderGroup** — группа слайдеров с pinned-навигацией
- **FeatureSection** — секция фичи с видео/изображением
- **MonitoringSection** — мониторинг и аналитика
- **BentoGrid** — bento-сетка с фичами
- **AudienceSection** — "Кому необходим Агент"
- **LaunchSection** — "Запуск и внедрение"
- **ComparisonSlider** — сравнение до/после
- **AwardsSection** — награды и достижения
- **BannerSection** — CTA-баннер
- **ProductsSlider** — слайдер других продуктов
- **FAQSection** — часто задаваемые вопросы
- **Footer** — подвал сайта

### Illustrations (Иллюстрации)
Интерактивные демонстрационные компоненты:
- **AgentChatDemo** — демо чата с агентом
- **AgentWorkflowDemo** — демо рабочего процесса

### Pages (Страницы)
Собранные страницы:
- **LandingPage** — полная страница лендинга

## Цветовая палитра

| Название | HEX | Использование |
|----------|-----|---------------|
| Violet Main | `#C16FFB` | Акцентный цвет, кнопки, теги |
| Violet Dark | `#300247` | Тёмный фон секций |
| Violet Light | `#EAD7FE` | Светлый фон, подложки |
| Black | `#15181F` | Основной текст |
| White | `#FFFFFF` | Светлый фон |
| Gray | `#E9EBF0` | Нейтральный фон |
